# Contributing

Issues and focused pull requests are welcome. Discuss changes that alter output contracts or hierarchy semantics before implementing them.

Build a Release configuration, run CTest, and format changed C++/CUDA files with the repository `.clang-format`. GPU algorithm changes should add a CPU-reference or invariant test and include reproducible benchmark evidence. Never commit profiler databases, downloaded scenes, binaries, or generated build trees.

By contributing, you agree that your contribution is licensed under this repository's MIT License and that you have the right to submit it.
