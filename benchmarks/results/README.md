# Recorded results

`hierarchy-rtx3050ti-cuda13.1.csv` contains the 30 raw CUDA-event samples summarized in `docs/PERFORMANCE.md`. `legacy-rtx3050ti-cuda13.1.csv` records the matching legacy whole-call wall-clock samples used for context.

Environment: NVIDIA GeForce RTX 3050 Ti Laptop GPU, 4096 MiB, compute capability 8.6; driver 590.44.01; CUDA 13.1.80; Linux x86-64; Release builds; five warmups.

Third-party OBJ files are not included. Input hashes are in `benchmarks/data/MANIFEST.md`.
